# Timer Sport

Chronomètre d'entraînement par intervalles, pensé pour le téléphone.

- Réglage du **nombre de tours**, du temps d'**effort**, du temps de **repos** et d'une **préparation** avant le départ
- **Durée totale** calculée automatiquement (pas de repos après le dernier tour)
- **Couleurs plein écran** : orange = préparation, vert = effort, bleu = repos, violet = terminé
- **Bips** : 3 bips courts sur les 3 dernières secondes, un bip long à chaque changement
- **Séances enregistrées** pour les relancer en un clic
- Pause, passer une étape, écran maintenu allumé pendant la séance
- Installable sur l'écran d'accueil et utilisable **hors ligne**

## Utilisation

Aucune installation : ce sont des fichiers statiques (HTML/CSS/JS).

En local : `python3 -m http.server` puis ouvrir http://localhost:8000.

En ligne : activer GitHub Pages (Settings → Pages → Deploy from a branch).

Sur iPhone, le bouton silencieux coupe les bips : laissez-le désactivé pendant la séance.
